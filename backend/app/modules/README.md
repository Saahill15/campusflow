# Modules

Organize feature domains into separate modules for scalable development.

## Suggested modules

- `landing/`
- `registration/`
- `auth/`
- `student_dashboard/`
- `admin_dashboard/`
- `qr_pass/`
- `payments/`
- `certificates/`
- `analytics/`
- `notifications/`
- `events/`

Each module may include its own routers, services, schemas, models, and tests.
