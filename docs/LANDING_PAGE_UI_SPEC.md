# Pragyarambh '26 Landing Page UI Specification

This document is the visual blueprint for the CampusFlow Pragyarambh '26 landing page. It defines layout, spacing, typography, motion, and visual structure for each section of the page.

## 1. Hero

### Purpose
The hero introduces the event with an aspirational, premium expression and a strong registration call to action.

### Desktop Layout
- Full-width hero with centered or left-aligned content.
- Content contained in a centered column no wider than 1180px.
- Two-column or layered composition: headline and CTA on one side, subtle visual treatment on the other.

### Tablet Layout
- Content shifts to a single column within a 720px width.
- Visual elements are reduced but still present as supporting accents.

### Mobile Layout
- Single column with full-bleed edge margins and a maximum content width of 360px.
- CTA remains immediately visible below the headline.

### Alignment
- Desktop: left-aligned or center-left for copy, with enough breathing room from the edge.
- Tablet: center-aligned with a slight left bias.
- Mobile: centered.

### Spacing
- Desktop vertical padding: 120–140px top, 120px bottom.
- Tablet vertical padding: 90–110px top and bottom.
- Mobile vertical padding: 70px top, 70px bottom.
- Internal spacing between headline, tagline, countdown, and CTA: 24px.

### Grid
- Desktop: 12-column grid with content spanning 6 to 7 columns and visual accents occupying the remainder.
- Tablet: 8-column grid with content spanning 8 columns.
- Mobile: single-column layout.

### Typography
- Event name large and distinct: use a bold display style.
- Theme name smaller, elegant, and supportive.
- Tagline medium weight and easy to scan.
- Countdown label and digits clear but not overpowering.

### Buttons
- Primary button large and full-width on mobile.
- Secondary button smaller and placed beside or below the primary CTA, depending on width.

### Cards
- Not applicable for hero.

### Images
- Use only subtle graphic accents or abstract shapes.
- Avoid literal photography in the hero.

### Icons
- Minimal use: a small arrow or countdown symbol can be included.
- Keep icon style refined and line-based.

### Animation
- Headline reveals first, followed by tagline and countdown, then CTA.
- Use gentle fade and upward movement.
- Keep motion slow enough to feel premium.

### Background
- A soft tonal surface with subtle pattern or texture.
- Accent usage limited to muted Retro Fusion details.
- No strong gradients or noise.

### Visual Hierarchy
- Event name as the anchor.
- Theme name and tagline provide context.
- Countdown adds urgency without dominating.
- Primary register button is the strongest visual element.

### Responsive Changes
- Countdown remains visible but scales down on tablet and mobile.
- CTA always remains visually prominent.
- Any decorative elements should simplify on smaller screens.

### Accessibility Notes
- Maintain contrast between text and background.
- Ensure CTA is large enough for touch.
- Headline and countdown should remain legible at all breakpoints.

## Visual Rhythm

### How whitespace should breathe
- Use generous vertical padding between sections.
- Allow each section to feel distinct yet connected.
- Avoid crowding content; let text and elements have room.

### How sections transition
- Each section should flow naturally from the previous one.
- Use consistent vertical spacing and subtle shifts in background tone to signal transitions.
- The eye should move downward in a calm, confident rhythm.

### How the eye moves
- Start at the hero’s bold event name, then to the supporting theme and CTA.
- The eye should travel through The Beginning narrative, move to the event definition, and then settle into the experience cards.
- Timeline, venue, and FAQ should feel like a controlled descent toward the final register action.

### How contrast is created
- Use scale, typography weight, and spacing to create contrast.
- Reserve accent colors for key actions and meaningful highlights.
- Keep background contrast subtle and focused on clarity.

## Consistency Rules

### Every section starts with title
- Each section should begin with a clear, confident heading.

### Maximum paragraph width
- Maintain a maximum reading width of 600px for body text on desktop.

### Maximum card width
- Keep cards within 380px on desktop to preserve readability and visual balance.

### Maximum content width
- Use a maximum page width of 1180px for primary content containers.

### Spacing consistency
- Use repeated spacing increments: 24px, 32px, 40px, 60px, 80px.
- Maintain consistent vertical rhythm across sections.

### Animation consistency
- Keep motion subtle and uniform.
- Use the same entrance easing and timing across sections.

## The Ideal Experience

The ideal landing page experience should feel like the opening chapter of a premium campus story. On first load, the visitor should experience a confident visual arrival: bold event identity, a subtle Retro Fusion mood, and a clear invitation to register. As they scroll, each section should feel purposeful and calm, with clean layouts, generous breathing room, and a measured rhythm.

The page should move gracefully from emotional connection to event clarity, from experience anticipation to practical confidence. The final register section should feel like a natural decision, supported by trust indicators and a calm sense of urgency. Overall, the visual experience should feel polished, modern, and memorable—an elegant introduction to Pragyarambh '26 rather than a generic event landing page.
