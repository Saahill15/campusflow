# Frontend Modules

Organize each major feature area as a module to support independent development and future expansion.

## Example module folders

- `landing/`
- `registration/`
- `dashboard/`
- `admin/`
- `events/`
- `payments/`
- `analytics/`
- `notifications/`
- `certificates/`
- `qr-pass/`

Each module can contain its own pages, components, hooks, and styles.
